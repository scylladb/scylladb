============================
Nodetool setstreamthroughput
============================
**setstreamthroughput** - Set the throughput cap for SSTables streaming in the system, in MiB/s

Setting zero throughput disables capping

Syntax
-------
.. code-block:: console

   nodetool [options] setstreamthroughput <value_in_mib>

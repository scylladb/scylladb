# Scylla Metric Update - Scylla 4.0 to 4.1

Scylla 4.1 Dashboards are available as part of the latest [Scylla Monitoring Stack](https://monitoring.docs.scylladb.com).

## The following LWT metrics are new in Scylla 4.1

* scylla_storage_proxy_coordinator_cas_dropped_prune
* scylla_storage_proxy_coordinator_cas_prune
* scylla_storage_proxy_replica_cas_dropped_prune
